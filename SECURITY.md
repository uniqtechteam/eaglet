# Security

Please report a security problem in eaglet privately, through
[GitHub private vulnerability reporting](https://github.com/uniqtechteam/eaglet/security/advisories/new),
not in a public issue.

We answer within 14 days, usually much sooner, and tell you what we will do and when. Once a fix is
released we publish an advisory and credit you, unless you would rather stay anonymous.

Supported versions: the latest release. Fixes are not backported to older `0.x` lines.
